# Element — Matrix client for HarmonyOS

**Element** is a secure, open-source messaging and collaboration app built on the
Matrix network. This HarmonyOS native application runs the full Element web client
on desktop and 2-in-1 devices.

## Features

- **End-to-end encrypted messaging** (E2EE) — chat, rooms and communities on Matrix
- **Full Matrix support** — DMs, group rooms, spaces, mentions, reactions, threads,
  typing indicators and read receipts
- **Voice & video calls** via Jitsi and Element Call widgets
- **File sharing, images and rich media** with encrypted media relay
- **Notifications** — native OS notifications and launcher badge for incoming messages
- **Persistent login** — your session survives restarts; no re-sign-in
- **Desktop layout** with the familiar Element three-panel interface on wide screens
- **2-in-1 support** — closing the window hides the app to the taskbar, still logged in

## Secure by design

- All messages are protected with end-to-end encryption by default
- Your account data and session keys are stored only in your device's sandbox
- No tracking, no ads, no data harvesting — your data stays on the Matrix homeservers
  you choose

## Privacy

- The app connects to the homeserver configured on first launch (default: matrix.org)
- Notifications work while the app is running
- This is a webkit-based wrapper around the open-source element-web client
  (Apache 2.0)

## Requirements

- HarmonyOS 6.0 or later
- Desktop (phone/tablet in landscape) or 2-in-1 form factor
